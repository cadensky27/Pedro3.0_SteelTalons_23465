# BIOBUZZ V5 — Pre-Competition Checklist

**When:** 1–2 days before the event. Complete the checks using the match-ready robot and software. Mark an item only when verified.

**Event:** ____________________  **Date:** __________  **Checked by:** ____________________

## 1. Robot Reliability & Cleaning

- [ ] **Inspect and tighten hardware.** Check drivetrain, wheels, motor mounts, mechanisms, and battery retention.
- [ ] **Inspect cable routing and connections.** Secure loose wiring; check XT30, RS485, motor, servo, and sensor connections. Keep wires away from moving parts.
- [ ] **Clean and inspect contact surfaces.** Clean mecanum wheels, intake/side rollers, and the flywheel; check for wear or damage.
- [ ] **Run all mechanisms through their full travel.** Verify there is no binding, interference, unusual noise, or looseness.

## 2. Code, Autonomous & Sensors

- [ ] **Verify match-ready software and configuration.** Confirm correct Auto and TeleOp programs, hardware names, Driver Station connection, and both gamepads.
- [ ] **Test every autonomous routine you intend to use.** Start from its actual starting position and verify shooting, paths, parking, and completion time.
- [ ] **Repeat autonomous runs for consistency.** Compare final positions, Pinpoint heading, path clearance, and performance across several runs.
- [ ] **Check shooter and mechanism performance.** Verify target RPM, recovery between shots, feeding, and intake/outtake under realistic loads.

## 3. Full Practice Match

- [ ] **Run at least one complete, timed practice match.** Include Autonomous, TeleOp, and endgame, using normal driver roles and game conditions.
- [ ] **Practice intended starting plans and alliance setups.** Check starting orientation, shot presets, navigation, and Auto-to-TeleOp transition.
- [ ] **Record performance and failures.** Note missed shots, jams, control mistakes, unexpected stops, slow cycles, and timing issues.
- [ ] **Fix critical issues and repeat affected tests.** After any hardware or code change, rerun the relevant tests and save the last verified code version.

## 4. Inspection, Team & Packing

- [ ] **Review inspection and match compliance.** Verify robot sizing, number plates, wiring, grounding, current software/app requirements, and legal attachments.
- [ ] **Charge and label power and control equipment.** Check match batteries, chargers, Driver Station, gamepads, cables, and charging supplies.
- [ ] **Review driver controls and match strategy.** Agree on roles, Auto choice, starting position, shooting plan, navigation use, and recovery procedures.
- [ ] **Pack and confirm inventory.** Robot, number plates, spare parts, tools, electronics, documentation, and protection for transport.
